# The Curious Case of Maple Manor

CCT360 Project 1 - Interactive Discovery

## What it is
A little mystery game. You walk around Maple Manor, find clues, talk to people, and guess who did the bad thing. The site remembers what you clicked.

## How to play
1. Open `index.html` in a browser (or use the GitHub Pages link).
2. Click around the hallway into rooms.
3. Get at least 2 clues and talk to at least 1 person so you can guess.
4. Right answer: **Mr. Pell (the cook)** because he said he was making breakfast at night.

## Folder stuff
- `index.html` = the pages
- `css/styles.css` = colours and layout
- `js/script.js` = the clicking / remembering stuff
- `images/` = pictures

## Stuff from class we used
- HTML sections for different screens
- CSS colours + a phone media query
- JavaScript variables for clues
- Functions like showScene and addClue
